# Требования и проверка

Источник: пользовательский файл TZ-YouTube-kopiya.docx, прочитан 3 ноября 2026.
Срок «10 дней с получения» указан в документе; дата получения от работодателя неизвестна.

Обязательные экраны: лента с превью; просмотр с лайками и комментариями; канал
с видео, плейлистами и подпиской; поиск по названию; загрузка с прогрессом и
метаданными; вход/регистрация; модерация с жалобами и скрытием.

Обязательная инфраструктура: FastAPI, PostgreSQL, Swagger /docs, объектное
хранилище, фоновая обработка, одна команда запуска на чистой Ubuntu.
Роли: пользователь, модератор, администратор. Приватные видео доступны только
тем, кому разрешил владелец. Критический путь: регистрация → загрузка → просмотр
→ лайк → комментарий. Нужны автотесты и воспроизводимые демо-данные.

Сдача: ZIP с полным Git-репозиторием и осмысленной историей, README, docs,
исходными файлами диалогов ИИ именно этого проекта и использованной агентной
обвязкой. Пересказ диалога не заменяет нативный экспорт. Секреты и чужие чаты
не входят в проект. Перед внешней отправкой владелец проверяет содержимое.

Описание вакансии упоминает схемы 20+ сущностей, VPN и Active Directory как
круг рабочих задач. В самом тестовом нет требования искусственно добавлять
20 таблиц, VPN, AD, платёжную систему или интеграцию LLM в видеосервис.

## Решения владельца

- 2026-11-03: ViewTube, русский интерфейс, визуальная структура близка к YouTube.
- Развёртывание: пользователь просит помощь без предварительных знаний; сначала локальная проверка, аренда/публичная публикация не заказывались.
- Приватные видео: только владелец и явно приглашённые зарегистрированные пользователи; роль модератора не даёт автоматического просмотра.
- Хранилище: SeaweedFS в составе проекта, подтверждено после проверки статуса MinIO.

# Происхождение разработки

Код создавался ИИ в чате Codex `01a1a14d-e714-77a0-85f2-afc12f7816ea` по поручению
владельца. Исходный запрос, уточнения, команды, результаты проверок и исправления
сохраняются инструментом в нативном JSONL (или его штатном сжатом JSONL.zst). Чаты других проектов не включены.
Дополнительная проверка и подготовка сдачи продолжены в чатах Codex
`01a1a1a8-5c19-7221-b5f4-1ee07bd3995e` и
`01a1a1cf-080f-7e80-8a8b-ed0c3abf7416`.
Другие агенты, Cursor и Claude для этого проекта не запускались. Работа разделена
на настоящие последовательные Git-коммиты, история не переписывалась.

## Правила и настройки

- `AGENTS.md` в корне — правила именно ViewTube.
- `agent-setup/global-AGENTS.md` — неизменённая копия пользовательских общих правил.
  iOS/Codemagic-разделы к этому web-проекту не применялись.
- `agent-setup/codex-config.toml` — исходная локальная конфигурация Codex как есть;
  включает локальные пути и настройки компьютера. Не является переносимой
  конфигурацией проекта, не копируйте её поверх своей.
- `agent-setup/*.mcp.json` — исходные манифесты использованных инструментов
  приложения/браузера. Авторизационные файлы аккаунтов не включены.
- `skills` — точные файлы, прочитанные при работе: documents (чтение DOCX), sites
  (маршрутизация и локальный preview), openai-docs (ознакомление с экспортом/инструментом).
  Основное приложение развёртывается самостоятельно: хостинг Sites не поддерживает
  требуемую комбинацию FastAPI/PostgreSQL/worker и для публикации не использовался.
- Файлы `agent-setup/*-20261112.*` — дополнительные неизменённые снимки
  актуальных общих правил и конфигурации при повторной приёмке 12 ноября.
  Исходные снимки 3 ноября сохранены; старые версии MCP-плагинов уже удалены
  из локального кэша, их исходные сохранённые манифесты проверены по SHA-256.
- `source-manifest.json` — исходные пути и SHA-256 неизменённых снимков.

Системные инструкции среды и встроенные browser-документы не являются авторской
«обвязкой» проекта; доступные сообщения о них присутствуют в нативном логе.
Глобальные токены входа, приватные runtime-секреты и файлы других чатов не копируются.
Конфигурация проверена на явные ключи credentials; это не заменяет просмотр
владельцем перед внешней отправкой. Архив остаётся локальным.

## Обновление ZIP

После коммита изменений:

```bash
python3 scripts/package.py \
  --session /absolute/path/to/original-codex-session.jsonl \
  --output /absolute/path/to/viewtube-submission.zip
```

Скрипт принимает исходную сессию проекта и дополнительные сессии, явно разрешённые
через `--allow-session-id UUID` (для каждого файла повторите `--session`), копирует её байты без очистки
или пересказа и добавляет весь `.git`. Записывает время снимка, commit и SHA-256
в `ai/sessions/manifest.json`. Активный диалог может продолжиться после снимка;
это ограничение указано явно. Для окончательной отправки можно повторить упаковку
после завершения диалога. Нельзя придумывать JSONL из отчёта о проделанной работе.

В ZIP входят только отслеживаемые исходники и `.git`, плюс нативный диалог.
`.env`, `.runtime`, резервные копии, зависимости, тестовые базы и медиа не входят.
Демо воспроизводится командой запуска. Снимки трёх диалогов для сдачи находятся
в `ai/sessions/`. При повторной упаковке содержимое этой папки в ZIP определяется
аргументами `--session`. В нативных диалогах есть локальные пути, условия задания
и временные тестовые данные.

### Сжатые нативные сессии

При проверке 12 ноября Codex уже хранил первую сессию как `.jsonl.zst`.
Упаковщик читает распакованные данные только для проверки ID, а в ZIP кладёт
исходный `.jsonl.zst` побайтно. Две другие сессии остаются `.jsonl`. Имя,
размер и SHA-256 каждого исходного файла записаны в манифесте. Для чтения
сжатого формата нужен Python 3.14+ либо утилита `zstd`; запуск самого приложения
этого не требует. Тест упаковщика проверяет сохранение обоих форматов.

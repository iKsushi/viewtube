# Происхождение разработки

Код этого проекта создаётся ИИ в текущем чате Codex по поручению владельца.
AGENTS.md содержит локальные правила. Реальные этапы фиксируются Git-коммитами.
Документация решений — пояснение, а не замена исходных диалогов.

Нативные сессии необходимо положить в отдельный каталог комплекта сдачи через
scripts/package.sh. Нельзя генерировать JSONL из пересказа или подменять экспорт.
Нельзя прикладывать глобальные MCP-конфиги с токенами и чужие переписки.
Снимки реально прочитанных SKILL.md хранятся в ai/skills; секретов в них быть не должно.
